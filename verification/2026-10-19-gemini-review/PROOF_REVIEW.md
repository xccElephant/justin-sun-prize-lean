## 1. 种子：确等式、互素、正性及 3-powerful

```text
Y  = 7 Y1 = 32295800804958334401937923416351
```

实际种子是 `(a,b,c) = (32 X^3, 16807 Y1^3, 81 Z^3)`。独立 Python 任意精度整数运算得到：

```text
32 X^3 + 16807 Y1^3 - 81 Z^3 = 0
32 X^3 + 49 (7 Y1)^3 - 81 Z^3 = 0
gcd(a,b) = gcd(a,c) = gcd(b,c) = 1
gcd(X,Y1) = gcd(X,Z) = gcd(Y1,Z) = 1
(a mod 3, b mod 3, c mod 3) = (1,2,0)
(v_2(a), v_7(b), v_3(c)) = (5,5,4)
```

这同时排除了参数抄写、漏掉 `Y = 7 Y1` 的系数换算、只核对参数互素而漏掉系数公共因子等问题。`49 * 7^3 = 16807 = 7^5`，注释中的原方程与代码中的种子确实一致。三个参数都正且种子的 `a,b > 1`，第三分量可由 `a+b=c` 得到正性；`3 ∣ c` 满足旧递推的关键不变量。

`32=2^5`、`16807=7^5`、`81=3^4` 的指数都至少为 3。系数均为 3-powerful，任何参数立方也为 3-powerful，乘法保持该性质。因此 `cohnSeedTriple_valid` 的三个 `Full` 证明在数学上正确，不需要参数本身是素数或与系数互素。

## 2. NonCube3FullClass 的定义和非立方证明

位置：1100–1137 行。

该类要求 `m > 0`，并允许三个形式的并集：`32 m^3`、`16807 m^3`、`81 m^3`。它是足够用于构造的特殊子类，并未定义成“所有非立方 3-powerful 数”。这种限制不会削弱最终无穷存在性结论，因为最终定理没有要求每个满足条件的三元组都由本构造产生。

三个非立方论证分别等价于下列质因子指数等式的不可能性：

```text
5 + 3 v_2(m) = 3 v_2(k)
5 + 3 v_7(m) = 3 v_7(k)
4 + 3 v_3(m) = 3 v_3(k)
```

左侧模 3 余数分别为 2、2、1，右侧余数为 0。即使 `m` 被对应的质数整除，余数也不会改变，故不存在隐含的 `p ∤ m` 假设。

源码在应用 `factorization_mul` 前明确证明 `m^3 ≠ 0` 和系数幂非零；这对于自然数 `factorization` 的零值约定是必要且充分的。已只读核对本地 mathlib 中 `factorization_pow` 与 `Prime.factorization_self` 的定义/陈述：幂的分解等于指数乘以底数分解，自身素数处指数为 1。所用 `factorization_pow` 对 `k=0` 也成立；此外等式假设和左侧正性已排除 `k=0`。未发现零值逃逸或把非立方证明错误用于零的情况。

类的注释声称其元素均为 3-powerful，在数学上同样正确。但代码没有单独输出“类成员推出 Full”的通用引理；这不是证明缺口，因为序列的 `Full` 结论另由 `ValidTriple` 及旧递推保证。

## 3. nextTriple 保持类、正性和有效性

新增位置：1170–1191 行。依赖旧代码：124–248 行。

`nonCube3FullClass_mul_cube` 使用恒等式 `d m^3 L^3 = d (m L)^3`，并由 `m>0`、`L>0` 取得新参数正性，三个分支均正确。

递推在 `a<b` 时为

```text
(a (b+c)^3, c (b-a)^3, b (a+c)^3),
```

在 `b<a` 时为

```text
(b (a+c)^3, c (a-b)^3, a (b+c)^3).
```

两个分支分别使用类成员顺序 `(a,c,b)` 与 `(b,c,a)`，与代码的 `.1`、`.2.2`、`.2.1` 和 `.2.1`、`.2.2`、`.1` 一致。联合类允许这种位置交换；无需永久固定每个坐标对应哪个系数。

`ValidTriple` 提供 `a,b>1` 和 `gcd(a,b)=1`。若 `a=b`，则 `gcd(a,a)=a=1`，与 `a>1` 矛盾，故不会出现差为零。`a≤b` 分支因此实际为 `a<b`，另一分支为 `b<a`；自然数减法得到严格正的 `b-a` 或 `a-b`，不会因截断减法引入零。两个加法乘子也严格正。

新序列有效性复用旧 `nextTriple_spec`。这不是假设结论：旧证明通过以下事实建立有效性。

1. 当 `c=a+b` 且 `a<b` 时，整数多项式恒等式
   `a(b+c)^3 + c(b-a)^3 = b(a+c)^3` 成立；代码在自然数差有序的前提下转到整数处理。
2. `gcd(a,b)=1` 给出 `gcd(a,c)=gcd(b,c)=1`。`gcd(b+c,a+c)` 整除 `3a` 和 `3b`，故只能是 1 或 3；如果等于 3，连同 `3` 整除原三分量之一及 `c=a+b` 可推出 `3∣a`、`3∣b`，矛盾。因此两个加法乘子互素。
3. 由上述互素因子，先得第一新分量与第三新分量互素，再由新加法恒等式得到第一与第二新分量互素。
4. 原来被 3 整除的分量仍作为某个新分量的因子，故 `dvd_three` 不变量保持。Full 由原 Full 乘立方保持。差立方至少为 1，保证新分量仍大于 1。

故新种子满足旧递推所需的全部条件，没有遗漏去除潜在公因子 3 的条件。

## 4. 无限性与最终 pairwise coprimality

位置：1194–1253 行。

两个归纳分别建立每项 `ValidTriple` 和三个坐标均属于 `NonCube3FullClass`；基例均来自已核对的种子，归纳步不相互循环依赖。

旧 `nextTriple_spec` 同时保证第三分量严格增长。以 `a<b` 分支为例，第三分量是 `b(a+c)^3`，其中 `b>1` 且 `(a+c)^3>c`，因此严格大于原 `c`；另一分支对称。这足以得到 `StrictMono (fun n => (cohnTripleSeq n).2.2)`。三元组相等蕴含第三分量相等，再由严格单调性得到指标相等，所以序列为单射；从自然数的无限性得到目标集合无限。没有仅证明“一项可不断递推”却遗漏不同项判别的问题，也没有只靠坐标置换制造假无限性。

最终目标是无条件的集合无限性；没有把关键数学事实藏入定理前提。目标明确含三个正性条件、三个 Full 条件、三个“对所有自然数 k 均不等于 k^3”的条件及 `a+b=c`。

最终三对互素来自：

```text
gcd(a,b)=1                         （hv.coprime）
gcd(a,c)=gcd(a,a+b)=gcd(a,b)=1
gcd(b,c)=gcd(b,a+b)=gcd(b,a)=1
```

已核对本地 mathlib 的 `coprime_self_add_right` 与 `coprime_add_self_right` 陈述，两个 `.mpr` 使用方向以及第二个使用 `hcop_ab.symm` 均与所需式子匹配。集合互素由集合包含互素的 `a,b` 得到，另有独立的三个 pairwise 条件；并未用集合互素错误替代 pairwise 互素。

这里“pairwise coprime”指**每个三元组内部**两两互素。定理不声称来自不同指标的任意两分量也互素；实际上旧分量作为后续分量因子，会否定这种跨指标解释。

## 5. 与 0882cf1 旧三元组主分支的区别

旧 `erdos_939.variants.triples`（当前 277–293 行）相对基准未改变。其种子是 `(271^3, 2^3*3^5*73^3, 919^3)`，允许立方；至少第一和第三分量为立方。旧递推每步只给原分量乘立方并置换，因此它本身不会把这种立方来源变成“全部非立方”的族。

新部分更换种子并增加保持非立方的证明，真正提供了旧族没有的“每个三元组三个分量全部非立方”性质。最终陈述还显式列出 pairwise 互素和 `c>0`。在 `a+b=c` 的三元组语境中，集合 gcd 为 1 已等价于 `gcd(a,b)=1`，继而推出三对互素；`c>0` 也由 `a,b>0` 自动推出。因此实质强化是**全部非立方**，而非额外解决一个旧定理没有涵盖的互素障碍。

不得把新增非立方要求说成旧三元组原问题成立的必需条件，或说基准证明因含立方而没有解决它陈述的三元组问题。新定理也不解决其他指数或其他子问题；本审查不对完整 #939 目录条目的提交资格作扩展判断。
